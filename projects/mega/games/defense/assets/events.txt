# 기간 한정 이벤트. 운영자가 시각만 바꿔 시즌을 여닫는다.
#
#   event <id> <이름> <start> <end> <period> <priority> [key=value]...
#
# start/end 는 유닉스 초이고 구간은 [start, end) 다 — 종료 시각은 포함하지
# 않는다. period 가 0 이면 1회성, 양수면 그 주기마다 [start, end) 창이 반복된다
# (period 는 창 길이보다 짧을 수 없다). priority 가 높은 이벤트의 수정자가 먼저
# 합성되고, 같으면 id 오름차순이다.
#
# 수정자 키와 허용 범위
#   scrap      0.25..4     매치 종료 정산의 메타 통화 배율
#   reward     0.25..4     매치 안 골드 보상 배율
#   enemy_hp   0.5..2      적 체력 배율
#   start_gold -500..2000  시작 골드 가감
#   blast_cost -500..1000  발파 비용 가감(음수면 싸진다)
#   boss_rush  0|1         보스 웨이브 편성
#
# 한 줄이라도 거부되면 파일 전체가 버려지고 이벤트 없이 돈다. 이벤트가 없는
# 상태는 결함이 아니라 정상 경로이므로, 절반만 켜진 시즌보다 언제나 낫다.

# 주말 2배 스크랩: 2026-01-03 00:00 UTC 부터 48시간, 이후 매주 반복.
event 1 weekend_scrap 1767398400 1767571200 604800 10 scrap=2.0

# 보스 러시: 같은 주말의 뒤쪽 24시간에만 겹친다. 우선순위가 높아 먼저 합성된다.
event 2 boss_rush 1767484800 1767571200 604800 20 boss_rush=1 enemy_hp=1.2 reward=1.5

# 발파 무료 주간: 2026-01-05 부터 7일간 한 번.
event 3 free_blast 1767571200 1768176000 0 5 blast_cost=-500
