# Engine

`engine/`은 개별 기능의 사용법보다 런타임 하위 시스템의 수명, 데이터 흐름, 스레드 경계, 통합 계약을 다룬다.

## 읽는 순서

| 순서 | 문서 | 핵심 질문 |
|---:|---|---|
| 1 | `part01_audio.md` | 실시간 오디오를 CPU·메모리·보이스 예산 안에 어떻게 유지하는가 |
| 2 | `part02_animation.md` | 포즈 평가·블렌딩·스키닝을 어떻게 구성하고 병렬화하는가 |
| 3 | `part03_vfx.md` | 대량 효과의 시뮬레이션과 fill-rate를 어떻게 제어하는가 |
| 4 | `part04_input.md` | 원시 입력을 결정론적인 게임 명령으로 어떻게 바꾸는가 |
| 5 | `part05_resource.md` | 에셋 바이트의 로딩·핸들·캐시 수명을 어떻게 관리하는가 |
| 6 | `part06_ui.md` | UI 상태·레이아웃·입력·배칭을 어떻게 통합하는가 |
| 7 | `part07_camera.md` | 게임플레이 카메라 상태를 어떻게 안정적으로 합성하는가 |
| 8 | `part08_runtime_orchestration.md` | 모든 하위 시스템을 프레임 단계와 작업 그래프로 어떻게 묶는가 |
| 9 | `part09_world_streaming_persistence.md` | 월드 셀·엔티티 수명·저장 복구를 어떻게 일관되게 관리하는가 |

`part05_resource.md`는 텍스처·메시·오디오 같은 에셋 바이트를 소유한다. `part09_world_streaming_persistence.md`는 어떤 월드 셀과 런타임 엔티티가 존재해야 하는지, 그 상태를 언제 활성화·퇴거·저장할지를 소유한다.
