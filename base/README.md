# 게임 개발을 위한 기초 CS

`base/`는 독립된 심화 이론을 다시 축약하는 시리즈가 아니다. 게임 개발자가 전체 커리큘럼에 들어가기 전에 공통 질문과 용어를 익히는 **진입 계층**이다.

각 글은 다음 네 질문에 답한다.

1. 이 분야는 게임의 어떤 상태와 실패를 모델링하는가.
2. 정확성을 지키는 불변식은 무엇인가.
3. 시간, 공간, 지연, 정확도 사이에 어떤 비용 교환이 있는가.
4. 측정과 검증으로 어떤 주장을 확인해야 하는가.

구체적인 자료구조 구현, 운영체제 내부, 그래픽스 API, 네트워크 프로토콜, 물리 해법은 해당 심화 시리즈가 소유한다. `base/`는 심화 구현을 일부만 잘라 복제하지 않고, 어떤 심화 축을 선택하더라도 필요한 큰 그림을 제공한다.

## 공개 순서

| 번호 | 제목 | 중심 질문 | 연결되는 심화 축 |
|---:|---|---|---|
| 01 | 프로그램은 어디에 시간을 쓰는가 | 비용을 어떤 단위로 모델링하고 측정하는가 | `parts`, `system` |
| 02 | 게임 상태를 어떻게 표현하는가 | 정수, 부동소수점, 좌표와 오차를 어떻게 다루는가 | `math`, `parts` |
| 03 | 자료구조와 데이터 배치 | 연산 계약과 메모리 배치를 어떻게 함께 선택하는가 | `algorithms`, `parts` |
| 04 | 알고리즘과 정확성 | 빠르다는 주장과 맞다는 주장을 어떻게 증명하는가 | `algorithms` |
| 05 | 추상화, 타입, 조합 | 변경 가능한 게임 코드를 어떤 경계로 나누는가 | `languages`, `engine` |
| 06 | 객체 수명과 메모리 | 소유권, 할당, 참조 안정성을 어떻게 설계하는가 | `parts`, `languages` |
| 07 | 컴파일러와 실행 런타임 | 소스 코드가 어떻게 실행되고 최적화되는가 | `languages`, `parts` |
| 08 | 동시성과 메모리 모델 | 여러 실행 흐름이 상태를 공유할 때 무엇이 깨지는가 | `parts`, `system` |
| 09 | 운영체제와 I/O | 프로세스가 커널과 장치를 어떤 계약으로 사용하는가 | `system` |
| 10 | 네트워크의 보장과 실패 | 지연, 손실, 순서, 혼잡을 어떻게 모델링하는가 | `network` |
| 11 | 멀티플레이 상태 동기화 | 서로 다른 시간축에서 하나의 게임을 어떻게 구성하는가 | `network` |
| 12 | 온라인 게임 서버 | 권위 상태와 서비스를 어떤 경계로 분리하는가 | `network`, `live_service` |
| 13 | 영속성과 데이터베이스 | 상태를 장애 뒤에도 일관되게 보존하는가 | `db`, `live_service` |
| 14 | 그래픽스 파이프라인 | 장면이 픽셀로 변환되는 동안 어디에서 비용이 생기는가 | `graphics`, `math` |
| 15 | 물리 시뮬레이션 | 연속 현상을 이산 시간에서 안정적으로 근사하는가 | `physics`, `math` |
| 16 | 게임 AI | 제한된 정보와 예산으로 믿을 만한 행동을 만드는가 | `ai`, `algorithms` |
| 17 | 게임 엔진 아키텍처 | 하위 시스템의 수명, 데이터, 스레드 경계를 어떻게 통합하는가 | `engine` |
| 18 | 게임 보안 | 신뢰할 수 없는 클라이언트와 운영 환경을 어떻게 다루는가 | `network`, `system` |
| 19 | 검증과 자동화 | 재현 가능한 빌드와 테스트가 어떤 오류를 막는가 | `tools`, 각 이론 축 |
| 20 | 배포와 라이브 운영 | 변경을 관측하고 실패 범위를 제한하는가 | `live_service`, `platform`, `tools` |

## 읽는 방법

위 순서대로 읽으며 각 장의 중심 질문에 답해 본다. 이미 익숙한 분야라면 필요한 질문부터 골라 읽고, 더 자세한 구현과 유도는 표의 심화 분야에서 찾아볼 수 있다.

성능 수치는 환경과 측정 방법을 함께 보고 해석한다. 코드 예제에서는 문법보다 어떤 메커니즘을 보여 주는지, 어떤 조건에서 실패하는지를 확인한다. 제품 버전이 달라져도 적용할 수 있는 기본 원리를 익히는 데 초점을 둔다.
